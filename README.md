# Dynamic Outline PDF (Unofficial)

An unofficial fork of [Dynamic Outline](https://github.com/theopavlove/obsidian-dynamic-outline) for Obsidian, extended with PDF bookmark support: floating Markdown headings and PDF bookmarks in one outline panel.

This is a personal fork maintained for a private study vault. It is not affiliated with the upstream project.

## Install via BRAT

1. Install the **BRAT** community plugin in Obsidian and enable it.
2. In BRAT settings, choose **Add Beta Plugin** and enter this repository: `Kotaro0121/obsidian-dynamic-outline-pdf`
3. Enable **Dynamic Outline PDF (Unofficial)** under Community plugins.
